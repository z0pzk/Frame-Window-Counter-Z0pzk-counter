# Frame Window Counter v3.0 — NaN Counter Edition (GD 2.2081 / Geode v5.11.2)

Полный ремейк в стиле **NaN Counter** (CBF / Frame Window Counter):
- **Починен баг «всегда 4 кадра»**: объекты уровня теперь индексируются в `PlayLayer::setupHasCompleted()` (в v2 `m_objects` в `init` был пуст), а Auto-симулятор прогоняет реальную траекторию выживания и бинарно находит границы окна с точностью до долей кадра (`0.77`, `1.45`, `5.3`).
- **Работает с ботами (Syndicate, xdBot, Eclipse, CBF)**: двойной перехват (`GJBaseGameLayer::handleButton` + `PlayerObject::pushButton/releaseButton`) с дедупликацией и автоматическим переподключением контейнера кружков к `m_objectLayer`.
- **Точный визуал NaN Counter**:
  - Таблица тиров слева сверху (`10+`, `8-10`, `6-8`, `5-6`, `4-5`, `3-4`, `2-3`, `1-2`, `0-1` или режим `1 / 2 / 3 / 4 / 5-6 / 7-8 / 9-12`) без фоновой коробки.
  - Белое мягкое свечение (**glow**) на сработавшей цифре в таблице.
  - Живые миллисекунды и Герцы (`8.29ms` / `121Hz`) прямо под таблицей.
  - Снизу слева — только 2 чистые белые цифры: `%` (оценка консистентности) и число сложности (**Raw Precision**).
  - Жирные кружочки с чёрной обводкой, которые **не пропадают** (можно включить/выключить) и показывают **просто число слева от круга без буквы `F`**.
  - Водяной знак справа сверху (переименовывается и отключается) + всплывающие комментарии справа (авто на 240Hz FP / высокий CPS или ручные).
  - Стартовый экран-легенда (режимы `Off` / `1st Try` / `Always`).
- **Починенная вкладка Manual**: кнопки `-0.1 / +0.1 / -1 / +1 / X` больше не перекрываются.

# Frame Window Counter v10.1 (GD 2.2081 / Geode v5.11.2)

Мод для точного подсчёта фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Исправление в v10.1
- **Убрано кривое масштабирование таблицы при смене Ref FPS**: теперь при `1000 FPS`, `360 FPS`, `60 FPS` или любом другом значении строки таблицы всегда остаются чистыми `1:`, `2:`, `3:`, `4:`, `5-6:`, `7-8:`, `9-12:`, `13-16:`, `17-24:` (или `0-1:`, `1-2:` в стиле CBF), где **`1:` = ровно 1 кадр для выбранного Ref FPS** (например, `1.00 мс` для `1000 FPS`).
- **Адаптивная точность для высоких FPS (>360 FPS)**: уменьшен шаг сканирования в `Auto` (`0.69 мс` вместо `1.04 мс`) и снижены нижние пороги для Волны и Корабля, чтобы 1-кадровые тайминги на `1000 FPS` считались корректно.
- **Авто-комментарии привязаны к кадрам выбранного FPS** (`<= 1.35F`), а не к жёстким `5.5 мс`.

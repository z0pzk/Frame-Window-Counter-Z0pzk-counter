# Frame Window Counter v4.0 (GD 2.2081 / Geode v5.11.2)

Мод для подсчёта и отображения фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Основные возможности
- **Универсальная совместимость с ботами**: работает с **Silicate**, xdBot, Eclipse, MegaHack, CBF, Speedhack и Frame Advance. Клики перехватываются и через `GJBaseGameLayer::handleButton` (поздний приоритет), и через прямое отслеживание `PlayerObject::m_isHolding` в `PlayLayer::postUpdate`, плюс корректно обрабатываются откаты/чекпоинты.
- **Точный Auto-режим по пику выживания**: на каждом клике симулятор сканирует сдвиги клика раньше и позже (`-28ms .. +28ms`), находит максимальную дистанцию выживания, отбрасывает смертельные сдвиги и бинарно вычисляет реальную ширину окна.
- **Статичные жирные кружочки**: 3 варианта толщины кольца (`Thin` / `Bold` / `Thick`) без изменения внешнего размера, без анимации на самих кружочках, числа без буквы `F`.
- **Таблица тиров с glow-подсветкой**: диапазоны `0-1 / 1-2 / ... / 10+` или `1 / 2 / 3 / 4 / 5-6 / 7-8 / 9-12`, белое свечение на обновляемой цифре, живые `ms` / `Hz`, и две чистые цифры снизу слева (`%` и индекс точности).
- **Ручной режим и ручные комментарии**: автоматическая запись кликов (`Capture Clicks`), ручное добавление маркеров (`+ Mark Here`), точная правка кадров (`-0.1 / +0.1 / -1 / +1`) и ручные всплывающие комментарии.
- **Водяной знак по центру сверху** (настраиваемый и отключаемый), стартовый экран-легенда (`Off` / `1st Try` / `Always`), встроенные колокольчики и поддержка любых своих звуков (`.wav`, `.mp3`, `.ogg`).

## Сборка через GitHub Actions
1. Загрузи все файлы из архива в корень репозитория GitHub (включая `.github/workflows/build.yml`).
2. Во вкладке **Actions** дождись завершения сборки `Build Windows (GD 2.2081 / Geode v5.11.2)`.
3. Скачай `.geode` из **Artifacts** и помести его в папку `geode/mods`.

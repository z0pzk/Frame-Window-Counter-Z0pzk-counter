# Frame Window Counter v2.0 (GD 2.2081 / Geode v5.11.2)

Обновлённая версия мода **Frame Window Counter**:
- **Нативный дизайн GD** (`GJ_square05`, стандартные чекбоксы, `goldFont`/`bigFont`, `TextInput` поля) вместо плоского «слопного» меню.
- **Нормальная квадратная кнопка в паузе**, которая автоматически встраивается в `left-button-menu` рядом с другими модами Geode (без наложений).
- **Исправленные кружочки кликов**: теперь рендерятся прямо в `m_objectLayer` (world-space) как чёткие сглаженные PNG-кольца прямо на месте клика — работают с зумом, камерой, шейдерами и покадровым шагом.
- **Физический 2D-симулятор в режиме Auto**: на каждом клике за микросекунды просчитывает сдвиги раньше/позже против шипов, блоков и орбов (Cube, Wave, Ship, Ball, UFO, Robot, Spider) вместо фиксированного запаса 22 мс.
- **Прямой ввод текста**: Reference FPS, Comment и Precision Line (пустые по умолчанию) можно вводить прямо в меню мода.
- **Классический колокольчик + свои звуки**: добавлен чистый классический звон `Classic` + папка для любых своих `.wav`/`.mp3`/`.ogg` прямо из вкладки `Audio` -> кнопка `Folder`.

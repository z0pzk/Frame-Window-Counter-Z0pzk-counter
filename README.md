# Frame Window Counter (Geode Mod for GD 2.2081)

Мод-счётчик фрейм-окон (FB-style Frame Window Counter) для **Geometry Dash 2.2081** на **Geode SDK v5.11.2**.

## Возможности
- **Режим Auto**: в реальном времени оценивает окно клика по близости к хитбоксам шипов/орбов и длительности нажатий (с нулевым лагом — объекты кэшируются один раз при загрузке уровня).
- **Режим Manual + Auto-Capture**: можно записать клики за прохождение/бота в один клик (`Capture Run Clicks`) или ставить маркеры вручную (`+ MARK HERE`), а потом настроить каждому клику точное количество кадров (включая `< 1F`, например `0.25F`, `0.50F`, `75F`) и тип (`Normal`, `S-Frame`, `Swift`, `Multiclick`, `Release`). Маркеры сохраняются автоматически отдельно для каждого уровня.
- **Анимация кружочков**: цветные кольца прямо на игроке с опциональной подписью кадров (`75F`, `0.50F`, `SWIFT`, `MULTI`).
- **Колокольчики и питч**: 4 встроенных `.wav` колокольчика (`Crystal`, `Soft`, `Tick`, `Deep`), настройка громкости, базового питча (`0.40x - 2.50x`) и **Dynamic Pitch** (чем жёстче окно, тем выше тон).
- **HUD слева снизу**: текущий клик (`F`, `~Hz`, `ms`), счётчики (`Clicks`, `FP`, `Avg`), специальные клики (`S-Fr`, `Swifts`, `Multi`), проценты (`FP%`, `Est%` — оценка вероятности прохождения) и живой `TPS`.
- **Стартовый баннер (Intro Showcase Banner)**: название уровня, комментарий (например `Open Window Top 1`), референсный FPS (`6000 FPS`, `100F`), строка `Raw Precision: 240Hz in-game` и цветовая легенда (например `< 76F: ~80Hz FP (8.33-12.50ms)`). Всё включается/выключается.
- **Совместимость с ботами и рендером**: не перехватывает ввод (всегда вызывает оригинальный `handleButton` первым) и привязывает все таймеры/кружочки/баннер к игровому `dt`, а не к реальному времени — при замедлении и рендере всё остаётся синхронизированным.

## Как скомпилировать на GitHub (без установки SDK на ПК)
1. Создай репозиторий на GitHub и загрузи все файлы из этого архива (обязательно вместе с папкой `.github/workflows/build.yml`).
2. Перейди во вкладку **Actions** в репозитории.
3. Дождись окончания сборки (`Build Windows (GD 2.2081 / Geode v5.11.2)`).
4. Скачай готовый `.geode` файл из раздела **Artifacts** и закинь его в папку `geode/mods` в Geometry Dash.

## Открытие меню в игре
Поставь уровень на паузу — в правом верхнем углу появится кнопка **`FWC`**.
Текстовые поля баннера (`Banner Comment` и `Raw Precision Text`) можно менять пресетами прямо в окне `FWC` или вписать свой текст в стандартных настройках мода в Geode.

# Frame Window Counter v10.2 (GD 2.2081 / Geode v5.11.2)

Мод для точного подсчёта фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Исправления в v10.2
- **Переписана физика Куба, Синих/других Орбов, Паука, Шара и НЛО (Волна и Кораблик не тронуты)**:
  - **Спам на синих орбах и кубике больше не даёт фейковые 1–2 кадра**: симулятор завершает проверку с успехом сразу при достижении следующего орба или чистом приземлении (2 тика), вместо того чтобы лететь дальше без нажатия следующего клика и умирать с фолбэком в 1 кадр.
  - **Буферные клики и клики в последний кадр**: расширено окно сканирования до `[-96ms, +96ms]` (до ~46 кадров @ 240Hz — последний клик Acheron на 21 кадр больше не режется в `0.3`), а клики в воздухе перед посадкой/орбом проецируются вперёд до реального контакта.
  - **Первый клик Acheron и узкие 1F в Auto**: мгновенное чтение реальной скорости `player->m_playerSpeed` (без запаздывания сглаживания) + резервная проверка `0.90x` на обязательных прыжках — одиночные 1-фреймы и 4-кадровые клики больше не пропускаются.
  - **Паук (Spider)**: телепорт идёт сразу к ближайшей поверхности и игнорирует шипы в воздухе по пути луча.
- **Починены D-блоки в Slaughterhouse**: исправлен Object ID D-блока (`1755` вместо `1814`) + добавлена проверка `onGround` для скользящей волны.
- **Исправлен `Scan Exact` на волне**: проверка сдвигов останавливается у следующего клика, а не тянет жёсткий рассинхрон на 0.6 сек вперёд (8-кадровые волновые клики больше не режутся вдвое до 4).

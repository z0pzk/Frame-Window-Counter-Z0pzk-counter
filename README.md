# Frame Window Counter v9.0 (GD 2.2081 / Geode v5.11.2)

Мод для точного подсчёта фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Новое в v9.0
- **Настоящие проценты сложности (`Difficulty %`)**: нижний левый процент больше не привязан к `%` уровня — он растёт только при кликах пропорционально сложности (`Raw Precision`), автоматически калибруется по плотности препятствий на первом проходе и запоминает точные `100.00%` сложности уровня после прохождения (или из `Manual` / `Scan Exact`).
- **Пауза на первом кадре для интро (`HUD -> Freeze Frame 0`)**: игра и боты (Silicate, xdBot, Eclipse) автоматически замораживаются на кадре `0`, пока показывается и плавно исчезает стартовая плашка — без пропусков кликов и без рассинхрона ботов.
- **Полная совместимость с рендером ботов**: добавлен универсальный физический детектор кликов (ловит клики даже если бот/рендер обходит `handleButton`) и гарантированное обновление HUD/кружков прямо в `GJBaseGameLayer::update`.
- **Встроенный лёгкий рендер (`Render`)**: рендерит уровень с кружками, таблицей, свечением, комментариями и заморозкой интро напрямую в `.mp4` через `ffmpeg.exe` с фиксированным `dt` (`30` / `60 FPS`, `Window / 720p / 1080p`), не сбивает ботов и почти не тратит оперативную память (~15 МБ).

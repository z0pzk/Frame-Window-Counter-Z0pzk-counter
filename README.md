# Frame Window Counter v5.0 (GD 2.2081 / Geode v5.11.2)

Мод для подсчёта фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Что нового в v5.0
- **Фильтр безопасных кликов (`Ignore Safe`)**: пустой спам на ровной земле, в широких тоннелях или далеко от препятствий больше не фармит `10+` и полностью игнорируется.
- **Новый геометрический анализатор для Волны (Wave)**: вместо прогона по прямой до потолка вычисляет реальный коридорный зазор (лучи до ближайших стен/шипов вперёд и назад, с отделением слопов от сплошных блоков) — убраны фейковые однокадровые клики на лёгких волнах и спам-челленджах.
- **Исправленный анализатор для Куба / Орбов / Корабля / НЛО**: сравнивает абсолютную координату `X` прохождения (а не относительную дистанцию) и сначала проверяет, грозит ли вообще смерть без клика.
- **Кастомные звуки под отдельные тиры (`Audio -> Per-Frame`)**: можно назначить свой звук (встроенный или любой `.wav`/`.mp3`/`.ogg`), **независимую громкость** и **независимый питч** для одного или нескольких диапазонов (например, отдельно для `0-1` и `1-2`), а все остальные тиры продолжат играть с общим звуком `Default (All)`.
- **Полная совместимость с ботами**: Silicate, xdBot, Eclipse, CBF, Speedhack и Frame Advance.

## Сборка через GitHub Actions
1. Загрузи все файлы из архива в корень репозитория GitHub (включая `.github/workflows/build.yml`).
2. Во вкладке **Actions** дождись завершения сборки `Build Windows (GD 2.2081 / Geode v5.11.2)`.
3. Скачай `.geode` из **Artifacts** и закинь в папку `geode/mods`.

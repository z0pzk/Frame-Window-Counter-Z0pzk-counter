# Frame Window Counter v6.0 (GD 2.2081 / Geode v5.11.2)

Мод для точного подсчёта фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Главные улучшения в v6.0
- **Real-Engine Pathfinder Scanner (`Scan Exact`)**: прогоняет реальный движок Geometry Dash (`PlayLayer`) по кадрам 240 Гц от контрольных точек перед каждым кликом. Автоматически проверяет, смертелен ли пропуск клика, сдвигает клик раньше и позже до столкновения (работает даже с Noclip) и сохраняет **100% реальное количество кадров** прямо в уровень для точного воспроизведения и рендера.
  - Работает на всех режимах и триггерах: Cube, Wave (включая любые слопы), Ship, Ball, UFO, Robot, Spider, Swing, Mini, Dual, орбы, батуты, Move/Rotate/Toggle-триггеры.
  - Если бот нажимает в первый кадр из 8 — сканер проверяет сдвиги в обе стороны и выдаст `8`, а не `1`.
- **Улучшенный Live Auto режим**:
  - Убрана лишняя галочка `Ignore Safe`.
  - Для Волны добавлена точная треугольная геометрия слопов (`Slope` с учётом поворота и отражений).
  - Починен Паук (`Spider`) и убрано искусственное сжатие хитбоксов на Кубе.
- **Убраны «призрачные» кружочки после перезапуска**: жёсткая очистка контейнера кружков на `resetLevel`, `resetLevelFromStart` и при откате бота в начало уровня.
- **Кастомные звуки под отдельные тиры (`Audio -> Per-Frame`)**: независимый звук, громкость и питч для любого выбранного диапазона кадров.

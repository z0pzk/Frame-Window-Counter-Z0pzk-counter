# Frame Window Counter v7.0 (GD 2.2081 / Geode v5.11.2)

Мод для точного подсчёта и отображения фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Что исправлено и добавлено в v7.0
- **Исправлен баг завышения `1F -> 3.8F` в Live Auto**:
  - Заменены константы прыжка на точные GD 2.2 (`670.802 u/s`, `3449.516 u/s^2`), убрано искусственное сжатие хитбокса и 14-юнитовый допуск выживания, а при приземлении симулятор продолжает проверять шипы (не завершается раньше времени).
  - Усилена проверка просвета для Волны (`Wave`) — реальные узкие коридоры больше не раздуваются до 9–12 кадров.
- **Улучшенный Real-Engine сканер (`Scan Exact`)**: сбрасывает зажатые кнопки между пробами, не тратит время на отпускания в Cube/Ball/UFO/Spider, проверяет до `±24` кадров с горизонтом `0.625` сек на реальном движке GD.
- **Яркий аддитивный Glow в таблице**: крупное мягкое белое свечение (`GL_SRC_ALPHA, GL_ONE`) с автоматическим центрированием по цифре + чёткий лёгкий импульс размера самой цифры при каждом новом клике.
- **Всплывающие комментарии справа (`Auto Comments`)**: автоматические подписи на 240Hz фрейм-перфекты (`1ST 240HZ FRAME PERFECT`, `CAN BE FROM ~(0.8-1.5)`, `BACK-TO-BACK`, `CPS SPAM`) + ручные комментарии во вкладке `Manual`. Отключается одной галочкой.
- **Стиль таблицы `1 -> 24`**: новый пресет (`1`, `2`, `3`, `4`, `5-6`, `7-8`, `9-12`, `13-16`, `17-24` сверху вниз) + прежние `0-1` и `1/2/3`.
- **Нижние `%` и Raw Precision**: процент теперь честно растёт от `0.00%` до `100.00%`, а формула Raw Precision откалибрована под реальные уровни.

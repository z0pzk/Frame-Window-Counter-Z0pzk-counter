# Frame Window Counter v8.0 (GD 2.2081 / Geode v5.11.2)

Мод для точного подсчёта и отображения фрейм-окон кликов (включая CBF / дробные кадры) в **Geometry Dash 2.2081**.

## Исправления в v8.0
- **Точный 0.9 Y-множитель движка GD 2.2 в Auto**: исправлено завышение одиночного 1-фрейм прыжка с `2.9F` до реального `1F` (`603.722 u/s`, гравитация `3104.565 u/s²`, `vy0 * 54`).
- **Округление кадров всегда вниз (`std::floor`)**: `2.9` -> `2`, `1.9` -> `1`, границы всех таблиц (`1->24`, `0-1`, `1/2/3`) строго выровнены.
- **Защита от кликов при смерти**: 2-тиковый буфер подтверждения (`~8 мс`) + мгновенная блокировка в `destroyPlayer` — клики в момент смерти или после неё больше не засчитываются.
- **Починен `Scan Exact`**: прямое создание и сохранение чекпоинтов (`createCheckpoint` + `storeCheckpoint`), прямой вызов оригинального `GJBaseGameLayer::handleButton` в обход сторонних ботов, `Priority::First` на `destroyPlayer` и диагностика `SKIP / FAIL`.
- **Очищены авто-комментарии**: убраны пронумерованные подписи `1ST / 2ND / 3RD 240HZ FRAME PERFECT`; оставлены `CAN BE FROM ~(...)`, `CPS SPAM` и ручные комментарии, привязанные к реальным `ms`.
